
## Relay

Цей проєкт веде задачі через Relay: повідомлення в Telegram → GitHub Issue →
план → код → реліз. Налаштування — у `relay.yml`, пайплайн — у
`.github/workflows/relay.yml`.

- **Специфікації** лежать у `docs/specs/<номер Issue>-<slug>.md`. Етап плану
  пише їх, етап коду виконує. Перш ніж змінювати код за задачею з Relay,
  прочитай її специфікацію.
- **Гілки:** `relay/<номер>-<slug>`, по одній на Issue. PR закриває Issue
  (`Closes #n`). Merge робить лише етап деплою після `/approve`.
- **Зелені тести** означають: команда `test` з `relay.yml` (або з пресету)
  завершується з кодом 0 без пропущених тестів. Тест, який «іноді падає»,
  вважається червоним.
- **Коментарі `## Relay · …`** в Issue — результати етапів. Їх не редагують;
  новий цикл етапу — новий коментар.
- Файли в `.relay/` — тимчасовий контекст для етапу; у git вони не потрапляють.
